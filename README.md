Offline GTA VI PS5 trophy guide + tracker with 55 trophies, roadmap visualizer, filterable categories, spoiler setting, and export/import functionality. Browse trophies by kind (platinum, story, side-story, activities, collectibles, robberies, partner, world, money, misc), hide missable/spoiler trophies, and track your progress locally.

## Run it

```bash
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open http://localhost:8080 (or open `app/index.html` directly).
